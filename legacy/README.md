# Legacy

De oorspronkelijke versie van Pixel Pigeon 3D, bewaard omdat de code nooit
echt in git terecht is gekomen: de enige commit ("Eerste upload van werkende game")
bevat 0 bytes voor alle drie de bestanden.

Wordt nergens meer door de game gebruikt. Weggooien mag, zodra je zeker weet
dat je hier niets meer uit nodig hebt.
